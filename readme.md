# Best Courses Ever

**Best Courses Ever** — это образовательная платформа, которая позволяет пользователям:

- Смотреть и редактировать курсы.
- Создавать собственные курсы.
- Оставлять комментарии к занятиям и курсам.
- Рейтинговать курсы и уроки для других участников.
- Видеть профили авторов курсов и редактировать их рейтинг.

## Технологический стек

- Backend: Node.js, ExpressJS
- База данных: MongoDB
- Шаблонизатор: Pug
- HTTPS: самоподписанный сертификат на этапе разработки

## Модели данных

- **User**: хранит данные пользователя, роль, профиль и информацию о созданных курсах.
- **Course**: хранит информацию о курсе, описание, уроки, теги, доступы пользователей, рейтинги.
- **Lesson**: отдельные уроки с описанием, ресурсами и комментариями.
- **Comment**: комментарии к урокам или курсам.
- **Resource**: файлы, видео и ссылки, связанные с уроками или курсами.

## API

Платформа предоставляет REST API для управления пользователями, курсами, уроками и комментариями.  
На этом этапе тесты API написаны, но реализация ещё не готова.

## Запуск проекта

1. Клонировать репозиторий
2. Установить зависимости: `npm install`
3. Сгенерировать самоподписанный сертификат для HTTPS
4. Запустить сервер: `npm start`
5. Основные страницы:
    - Главная страница с курсами
    - Страница отдельного курса
    - Авторизация и регистрация (пока без функционала)
